# GD Launcher

A modern and lightweight launcher for **Geometry Dash**, built with **C#** and **WinUI 3** by **Leisure Works**.

## ✨ Features

* 🚀 Fast and simple Geometry Dash launching
* 🎮 Designed specifically for Geometry Dash
* 🪟 Modern Windows UI powered by WinUI 3
* ⚡ Lightweight and easy to use
* 🔄 Launcher updates and management
* 🧩 Mod and Geode integration *(planned)*

## 🛠️ Tech Stack

* **C#**
* **.NET**
* **WinUI 3**
* **Windows App SDK**

## 📦 Status

> 🚧 **Early Development**

GD Launcher is currently under active development. Features and APIs may change frequently.

## 🏗️ Building

### Requirements

* Windows 10/11
* Visual Studio 2022 or newer
* .NET SDK
* Windows App SDK

### Build

Clone the repository:

```bash
git clone https://github.com/leisure-works/GD-Launcher.git
cd GD-Launcher
```

Open the solution in **Visual Studio** and build the project.
